# Support

## How to get help

This repository contains samples and learning materials. It is not covered by a
Microsoft support contract or service-level agreement.

Before opening an issue:

1. Review the relevant cookbook and the latest [wiqd documentation](https://microsoft.github.io/wiqd/).
2. Search [existing issues](https://github.com/microsoft/plugins/issues) for a
   solution or known limitation.
3. Confirm that the issue can be reproduced with the currently documented
   prerequisites and tool versions.

If the problem is specific to this repository, open a
[GitHub issue](https://github.com/microsoft/plugins/issues/new) with the affected
cookbook, reproduction steps, expected and actual behavior, and relevant
sanitized output. Do not include secrets, credentials, personal data, or tenant
data.

For suspected security vulnerabilities, follow [SECURITY.md](SECURITY.md) and do
not open a public issue. For official Microsoft product support, use the support
channel associated with that product or your Microsoft support agreement.
